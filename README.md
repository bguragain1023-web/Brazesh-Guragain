## Introduction

Welcome to my professional portfolio website. This project serves as a central hub to showcase my journey as a Full Stack Developer and Software Engineering student. It highlights my technical skills, completed projects, and professional background in a clean, responsive, and interactive format.

## Features

**Responsive Design:** Fully optimized for desktop, tablet, and mobile devices using a custom navigation menu.

- **Typing Animations:** Dynamic visual effects for my name and professional roles to engage visitors.
- **Project Showcase:** A grid-based layout featuring cards for major projects like the Time Tracker and Weather Dashboard.
- **Resume Integration:** Direct links for visitors to view or download my professional CV.
- **Single Page Architecture:** Built as an SPA for smooth transitions and fast performance.

## Technologies used

- **Frontend:** React.js (Vite)
- **Styling:** Bootstrap 5 & Embedded CSS
- **Tools:** Git, GitHub
- **Deployment:** Vercel and Domain

## How to use (Installation)

To run this project locally, follow these steps:

```
# Clone the repository
git clone https://github.com/bguragain1023-web/Brazesh-Guragain.git

# Navigate into the project directory
cd Brazesh-Guragain

# Install dependencies
yarn

# Run the development server
yarn dev

```

## Usage

Once the development server is running, open http://localhost:5173 in your browser. You can navigate through the different sections using the navigation bar. The project cards are interactive and provide insights into my recent work.
